# Plan 4 of 4 — Ship Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Anyone can download `ArabicRelay-Setup-0.1.0.exe` from GitHub Releases, install it without admin rights, get
signed automatic updates, and report problems with Copy diagnostics. Developers can `pip install` it from GitHub. The
owner moves from the old exe to the installed app with their vocabulary intact.

**Architecture:** `__main__.main()` becomes the one entry point for every role (window, `--speech-worker`, `--setup`,
`--browser`, new `--self-test`). The new `diagnostics.py` owns logs, crash capture, the diagnostics report and the
self-test. The new `updates.py` checks GitHub Releases daily, downloads in the background, verifies the Ed25519
signature, and runs Inno Setup silently. PyInstaller (folder mode) and Inno Setup turn the package into Setup.exe.
`scripts/build.ps1` builds both locally and in GitHub Actions. `scripts/sign_release.py` signs a draft release
offline and publishes it.

**Tech Stack:** Python 3.13 stdlib (`logging.handlers`, `ctypes`, `socket`, `urllib`, `tomllib`), `cryptography`
(Ed25519), PyInstaller 6.22.3, Inno Setup 6, GitHub Actions (`windows-latest`), `gh` CLI, gitleaks, Node for UI tests.

**Spec:** `docs/superpowers/specs/2026-10-20-public-release-design.md` — Part 4 (the repo layout, the docs and the
pre-push checks), Part 5, and Part 6 (the rows that Plans 1–3 left open). Plans 1–3 are merged.

- Preferred port `8791`; a busy port falls back to a free one. The owner's WebView2 storage (theme, dictation
  provider, vocabulary hints) is keyed by `http://127.0.0.1:8791`, so 8791 must win whenever it is free.

  the repo. Public key: 32 raw bytes as hex in `updates.PUBLIC_KEY`.

## Review Focus

1. **The owner's data survives the switch.** Vocabulary, T3 sign-in, prompt choice and the 8791-keyed hints must all
   be there in the installed app — Task 3 `test_bind_prefers_the_requested_port`, Task 12 checklist.
2. **An update that fails its signature is never run.** Tampered file, wrong key, missing `.sig`, or a file swapped
   after download — Task 5 `test_tampered_or_unsigned_update_is_deleted` and `test_install_reverifies`.
3. **An update never interrupts work.** Install is refused while a transcription, translation, send or model
   download holds its lock — Task 5 `test_install_refused_while_busy`; Task 6 disables the button while recording.
4. **A second launch while the first is still starting** (mutex taken, `instance.json` missing or half-written) must
   exit quietly — Task 3 `test_focus_tolerates_missing_or_bad_instance_file`.
5. **A silent uninstall keeps the user's data.** Only an interactive Yes deletes it — Task 9 smoke step asserts the
   data folder survives `/VERYSILENT` uninstall.
