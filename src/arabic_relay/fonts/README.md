# Local typefaces

Bundled for offline use by Arabic Relay. All fonts are licensed under SIL Open Font License 1.1; the original notices are included alongside them.

- Geist.ttf (body, served as the `Relay` family): Google Fonts repository, `ofl/geist/Geist[wght].ttf`. Notice: Geist-OFL.txt.
- InstrumentSerif-Italic.ttf, InstrumentSerif-Regular.ttf (headings): `ofl/instrumentserif/`. Notice: InstrumentSerif-OFL.txt.
- DMMono-Regular.ttf (labels, buttons, metadata): `ofl/dmmono/DMMono-Regular.ttf`. Notice: DMMono-OFL.txt.
- NotoSansArabic.ttf (Arabic text): `ofl/notosansarabic/NotoSansArabic[wdth,wght].ttf`. Notice: Noto-OFL.txt.

Source: https://github.com/google/fonts. Downloaded without modification for the October 19, 2026 Monologue redesign. No external font service is called at runtime.
